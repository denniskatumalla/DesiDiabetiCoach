Claude Code Environment

Complete setup for Development → Staging → Production with Claude Code. Windows (PowerShell) primary.

Claude Code v2.1+ Next.js 14 Supabase React Native / Expo
Step 01

Install Claude Code

Two options: Desktop app (easiest) or CLI via npm. You need a Claude Pro, Max, Team, or Enterprise subscription.

A
Option A — Claude Desktop (Recommended)
Download Claude Desktop from claude.ai/download. Available for Windows (x64 + ARM64). After install, sign in and click the Code tab in the top nav.
URL 
https://claude.ai/download   ← Download here, sign in with your Anthropic account
Note: On Windows, Git must be installed for local sessions. Download from git-scm.com with default settings.
B
Option B — CLI via npm (PowerShell)
For terminal-based workflow. Requires Node.js 20+.
PowerShell — Run as Administrator 
# Check Node.js version first (must be 20+)
node --version

# Install Claude Code globally
npm install -g @anthropic-ai/claude-code

# Authenticate (opens browser)
claude login

# Verify installation
claude --version
Step 02

Set Up the Project

Get the project files onto your machine and run the automated setup script.

✓ Claude automatically reads CLAUDE.md at the start of every session — giving it full context about the project, tech stack, database schema, and coding standards. No re-explaining needed.
Step 03

Three Environments Explained

Dev → Staging → Production. Each has its own database, secrets, and deploy process.

Environment 01

🖥 Development

  • Runs entirely on your Windows machine
  • Supabase DB runs in Docker
  • URL: localhost:3000
  • Start: npm run dev:web
  • DB UI: localhost:54323
  • Email: localhost:8025 (Mailhog)
  • Branch: any feature branch
  • Secrets: .env.local (never commit)
Environment 02

🧪 Staging

  • Cloud environment for testing
  • Auto-deploys from: develop branch
  • URL: staging.desidiabeticoach.com
  • DB: Supabase cloud (staging project)
  • Deploy: push to develop branch
  • Secrets: Vercel environment variables
  • Use for: QA, demos, client reviews
  • Claude command: /deploy-staging
Environment 03

🚀 Production

  • Live app — real users
  • Deploys from: main branch ONLY
  • URL: www.desidiabeticoach.com
  • DB: Supabase cloud (prod project)
  • Deploy: PR to main + manual approval
  • Secrets: Vercel production env vars
  • NEVER deploy directly from dev
  • Requires GitHub environment approval

Step 05

Daily Development Commands

Everything you need for day-to-day development in PowerShell.

npm run dev:dbStart local database (Supabase in Docker). Run this first, before anything else.
npm run dev:webStart Next.js web portal at http://localhost:3000
npm run dev:mobileStart Expo mobile app. Scan QR code with Expo Go on your phone.
npm run testRun all tests. Must pass before any deploy.
npm run db:seedSeed the South Asian food database (500+ dishes) into local DB.
/dev-statusClaude Code slash command — checks what's running and what needs attention.
/new-migrationClaude Code slash command — creates a new DB migration file with correct naming.
/deploy-stagingClaude Code slash command — runs tests, builds, and pushes to staging safely.

Secrets & API Keys Needed

Fill these into .env.local for dev. Add them to Vercel dashboard for staging/prod.

VariableWhere to Get ItExample / Notes

NEXT_PUBLIC_SUPABASE_ANON_KEY Supabase project → Settings → API eyJhbGciOiJIUzI1N... REQUIRED
SUPABASE_SERVICE_ROLE_KEY Supabase project → Settings → API eyJhbGciOiJIUzI1N... (secret!) REQUIRED
RESEND_API_KEY resend.com → API Keys re_xxx... (free tier: 3K emails/mo) optional
APP_SECRET Generate locally Run: openssl rand -hex 32 REQUIRED
⚠ Security: Never commit .env.local to Git. The .gitignore already blocks it. For Vercel (staging/prod), add these under Project → Settings → Environment Variables.
